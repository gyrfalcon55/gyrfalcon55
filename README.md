### 📌 Featured Projects

**🩺 [EfficientNet-Based Skin Lesion Diagnosis with Explainable AI & Report Generation](https://github.com/gyrfalcon55/Skin-Lesion-Diagnosis-and-Report-Generation)**
Deep learning system classifying seven skin disease types using EfficientNet on the HAM10000 dataset, achieving an **89% weighted F1-score**. Integrated Grad-CAM for interpretability and LangChain + OpenAI API for automated diagnostic report generation. Deployed on Azure with a Streamlit front end.
`Python` `TensorFlow` `Keras` `OpenCV` `Flask` `OpenAI API` `LangChain`

**📄 [Legal Contract Processing & Clause Extraction Pipeline](https://github.com/gyrfalcon55/Document_Processing_with_LLMs)**
RAG-based pipeline for contract understanding, using LangChain + ChromaDB for semantic search across 50+ contract documents. Locally hosted LLMs (via Ollama) extract structured clauses — termination, confidentiality, liability — across multiple document formats.
`Python` `LangChain` `ChromaDB` `Ollama` `Pydantic` `RAG`

**🎬 [IMDB Sentiment Analysis — End-to-End NLP Pipeline with MLflow & FastAPI](https://github.com/gyrfalcon55/IMDB_Sentiment_Analysis)**
End-to-end NLP pipeline on 50,000 IMDB reviews with Logistic Regression, Naive Bayes, and SVM models, tuned via RandomizedSearchCV. Experiments tracked with MLflow/DagsHub, dataset versioned with DVC, and served through a real-time FastAPI web app.
`Python` `Scikit-learn` `NLTK` `FastAPI` `Docker` `Git`
